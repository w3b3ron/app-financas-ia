# app-financas-ia

App responsivo (celular e web) de finanças pessoais com módulo de investimentos (FIIs, ações, stablecoins, estratégias com opções) e uma camada de IA que **explica** análises calculadas por código determinístico.

**Estado:** fase de ideia e design. Ainda não há código do app.

## Conteúdo
- `docs/HANDOFF.md`: documento de passagem. Comece por ele.
- `docs/IDEIA.md`: resumo da ideia e link para o documento completo.
- `design/`: proposta visual de 3 telas (Painel, Ativo, Simulador de opções) em celular e web. Dados de exemplo.
- `AGENTS.md`: regras para agentes e desenvolvedores.
